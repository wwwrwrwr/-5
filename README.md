# LINGUA — Языковая школа

Многостраничный сайт языковой школы: главная страница, каталог курсов с калькулятором стоимости обучения и страница записи с валидацией формы.

## О проекте

Сайт создан в рамках учебного проекта по дисциплине разработки веб-приложений. Команда работала по Git-флоу с ветками `main` и `develop`, feature-ветками для каждой задачи и обязательным Pull Request с проверкой перед слиянием.

## Как запустить

Сайт полностью статический, сервер не требуется.

**Вариант 1 — открыть напрямую в браузере**
1. Скачай или склонируй репозиторий:
git clone https://github.com/wwwrwrwr/-5.git

2. Открой файл `index.html` двойным кликом или через браузер (Файл → Открыть файл)

**Вариант 2 — через Live Server (рекомендуется)**
Открытие напрямую через двойной клик иногда ограничивает работу скриптов (например, если браузер блокирует локальные файлы). Чтобы избежать этого:
1. Установи расширение Live Server в VS Code
2. Открой папку проекта в VS Code
3. Правой кнопкой на `index.html` → Open with Live Server
4. Сайт откроется в браузере по адресу вида `http://127.0.0.1:5500`
